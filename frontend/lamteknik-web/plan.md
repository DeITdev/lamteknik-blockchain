# LamTeknik web UI

Next.js SaaS frontend for the accreditation workflow. See `.env.example`.

| Variable | Local value |
|---|---|
| `NEXT_PUBLIC_API_URL` | `http://localhost:3001/api/v1` |
| `NEXT_PUBLIC_IPFS_GATEWAY` | `http://localhost:8080` |
| Dev port | `3002` (`npm run dev`) |

Run: `cp .env.example .env.local && npm install && npm run dev`
